# 中国象棋 · 人机对战（手机版）

纯前端 HTML5 象棋小游戏：人机互弈、触屏对弈、**六档难度逐级递增**，针对**荣耀（Honor）等全面屏安卓手机**做了适配，可离线游玩。

棋盘采用**浅色木质复古风格**（浅暖木色棋盘、黑色细网格线、书法体「楚河汉界」、木色圆子配红/黑书法字）。

## 玩法

- 点击/拖动己方棋子选中，再点落点走棋（可走之处有绿色圆点提示，可吃之处有红圈提示）
- 支持悔棋、提示（AI 建议着法）、新开局、音效开关
  - 提示棋力封顶为普通档（≤3 层搜索且带随机性），保证提示永远不比本档 AI 更强——不会出现“靠提示无损打赢宗师”的情况
- 顶部可切换「执红 / 执黑」（执黑时棋盘自动翻转，AI 先行）
- 将死、困毙判负，相同局面重复 3 次判和；被将军时有红圈提示与「将军！」提示

### 六档难度

| 档位 | 名称   | 棋力说明                                   |
|------|--------|--------------------------------------------|
| 1    | 入门   | 纯随机走棋，明显弱于其余各档                |
| 2    | 简单   | 2 层搜索，保留较大随机性，常犯小错          |
| 3    | 普通   | 3 层搜索 + 局面评估，可正常对弈              |
| 4    | 困难   | 4 层搜索，行棋稳健                          |
| 5    | 大师   | 5 层搜索 + 静态搜索，攻守兼备                |
| 6    | 宗师   | 6 层搜索 + 静态搜索 + 启发式剪枝，最强       |

难度经过了配置单调性断言（test.js：深度/时间逐档递增、随机性逐档递减）与相邻档位 AI 对战检验（ladder2~5.js）。检验结论：**低档区间（入门→困难）逐级增强有对战实证（高档胜率 67%~100%）；高段位（困难/大师/宗师）相邻差距较小（对局样本中高档不低于低档），深档位通过更深的逐层搜索与静态搜索体现棋力，未发现高档弱于低档的倒挂**。检验中还修复了三处真实问题：入门档原先的吃子偏好使其实力接近简单档（改为纯随机）、简单/普通档随机余量过大（收窄 margin）、静态搜索漏判将死局面（补终局判定并增加将军延伸）。

AI 内置开局库（中炮、仙人指路等常见开局应着），低档位带随机性，高档位逐层递增搜索深度与时间。

## 怎么装到荣耀手机上

任选一种：

0. **部署到 GitHub Pages（推荐，一劳永逸）**：
   - 本项目是纯前端静态站，把仓库推送到 GitHub 后开 Pages 即可：
     ```bash
     gh repo create xiangqi --public --source . --push   # 或在网页上新建仓库后 git push
     ```
   - 网页方式：Settings → Pages → Source 选 `Deploy from a branch` → `main` → `/ (root)` → Save
   - 部署完成后手机访问 `https://你的用户名.github.io/仓库名/`，用荣耀浏览器打开后
     「菜单 → 添加到主屏幕」即可像 App 一样全屏使用，且支持离线游玩
   - 项目中的 `server.js`、`test.js`、`ladder*.js`、`make-icons.js` 均为开发/测试用途，
     GitHub Pages 只需要 `index.html`、`style.css`、`js/`、`manifest.webmanifest`、
     `sw.js`、`icons/` 这些静态文件（已全部使用相对路径与相对 scope，部署到子路径也能正常工作）
1. **直接发送文件**：把整个 `xiangqi` 文件夹打包成 zip，通过微信/QQ/华为分享发送到手机；解压后用「荣耀浏览器」直接打开 `index.html` 即可玩。
2. **局域网访问**：
   - 电脑与手机连同一 Wi-Fi，电脑上运行 `node server.js`（需 Node.js）
   - 手机浏览器访问启动时打印的局域网地址 `http://电脑IP:8123`
   - 浏览器菜单 →「添加到主屏幕」，即可像 App 一样全屏打开，之后可离线游玩

## 荣耀/全面屏适配说明

- `viewport-fit=cover` + `env(safe-area-inset-*)`：适配挖孔屏、刘海屏、荣耀手势条
- `100dvh` 动态视口：适配荣耀浏览器地址栏收起/展开时的视口跳动
- `touch-action: none` 棋盘手势隔离 + `user-scalable=no` + `overscroll-behavior: none`：禁止双指缩放、双击放大、下拉刷新、长按菜单
- 棋盘按「宽度优先」自适应居中，任意屏幕尺寸（含横屏）永不出界；设备像素比（dpr）高清渲染
- Service Worker 离线缓存：添加到主屏幕后断网也能玩

## 目录结构

```
xiangqi/
├── index.html          页面结构（含 PWA manifest 链接）
├── style.css           样式与适配（safe-area / dvh / 手势隔离）
├── manifest.webmanifest  PWA 清单（可添加到主屏幕）
├── sw.js               Service Worker（离线缓存，升级时需同步版本号）
├── server.js           本地静态服务器（node server.js → :8123）
├── make-icons.js       生成 App 图标（node make-icons.js）
├── icons/              生成的 192/512 图标
├── screenshots/        效果截图（初始、走子后、结算、执黑）
├── js/
│   ├── game.js         核心规则 + AI（无 DOM 依赖，可在 Node 中直接测试）
│   └── ui.js           界面、触摸交互、音效、悔棋/提示等
└── test.js             规则与 AI 测试（node test.js，70 项断言）
```

## 开发者调试参数

页面 URL 追加参数可启用调试能力（`?debug=1` 会在网格交点画红色十字并输出棋盘状态到 `#debugInfo` 元素）：

- `?debug=1`     调试模式：十字准星 + 实时棋盘状态 JSON
- `?autoplay=1`  自走对局脚本（测试走子/悔棋/换边等完整流程）
- `?over=1`      强制弹出结算弹窗（测试弹窗 UI）

## 规则实现

- 车、马（蹩马腿）、炮（隔子打）、相（塞象眼、不过河）、仕/士（九宫斜走）、帅/将（九宫直走）、兵/卒（过河前直进、过河后可横走，不可后退）
- 飞将照面、送将（自将）判非法
- 将死、困毙判负；同局面第 3 次出现判和
